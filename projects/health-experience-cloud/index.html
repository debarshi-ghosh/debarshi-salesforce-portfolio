Health & Experience Cloud — Global Patient Support

An anonymized program-level view of portal delivery, identity and consent architecture, secure integration and multi-country Salesforce releases.

Program overview

Led Health Cloud and Experience Cloud implementation work supporting global Patient Support Programs. The program included portal experiences for external users, integration with enterprise systems and privacy-aware handling of sensitive information.

Delivery scope

  • Health Cloud and Experience Cloud implementation delivery.
  • Portal applications supporting more than 1,500 users.
  • Identity and Consent Management architecture.
  • Secure REST/SOAP integrations and controlled data access.
  • Access controls using Sharing Rules, Sharing Sets, Field-Level Security and Permission Sets.
  • Architecture validations, design walkthroughs, code reviews and production root-cause analysis.
  • Documentation and coordination across distributed Agile delivery teams.

Scale and outcomes

The overall patient support program delivered 12+ major releases and 30+ country rollouts with zero Sev-1 production defects, as stated in the resume. The associated integration architecture handled 10,000+ daily transactions and reduced integration discrepancies by 40%.

Experience Cloud applications managed more than 1 million records. LWC optimization, selective SOQL and Apex heap tuning contributed to a 25% improvement in engagement. Production issue-resolution time was reduced by 35% through RCA and performance tuning.
