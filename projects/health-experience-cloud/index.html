Health & Experience Cloud — Global Patient Support

Scaling secure digital program experiences for a global patient-support environment through portal delivery, identity and consent architecture, reliable integrations and performance engineering.

Business challenge

Global Patient Support Programs require dependable digital experiences for large external user communities, while handling sensitive information through controlled access and consent-aware processes. The delivery scope documented in the resume points to the need to support more than 1,500 portal users and applications managing over 1 million records, while coordinating Salesforce with connected enterprise systems.

At this scale, the key business and technology needs were to establish trusted identity and consent controls, keep data exchange reliable across systems, provide a responsive portal experience, and deliver enhancements consistently across a multi-country program.

This challenge statement is inferred from the documented program scope and scale. The resume does not specify the client's original portal limitations, individual patient journeys, source-system names or a quantified pre-implementation baseline, so those details are not assumed.

Solution overview

Led Health Cloud and Experience Cloud implementation work for global Patient Support Programs. The delivery combined portal applications, Identity and Consent Management architecture, secure REST/SOAP integrations, granular Salesforce access controls and ongoing performance optimization.

How the solution addressed the need

  • Enabled digital program access at scale: Health Cloud and Experience Cloud implementation supported portal applications serving more than 1,500 users.
  • Strengthened identity and consent governance: Designed Identity and Consent Management architecture and applied controlled access to sensitive information.
  • Connected Salesforce with enterprise systems: Secure REST/SOAP integrations supported more than 10,000 daily transactions, with integration improvements focused on reducing discrepancies.
  • Protected sensitive data: Applied Sharing Rules, Sharing Sets, Field-Level Security and Permission Sets, alongside secure authentication, authorization, encryption and API practices.
  • Improved portal responsiveness at scale: Optimized Experience Cloud applications managing more than 1 million records using LWC optimization, selective SOQL and Apex heap tuning.
  • Supported reliable global delivery: Contributed to architecture validations, design walkthroughs, code reviews, distributed Agile delivery and production root-cause analysis across a multi-country release program.

My role and contribution

Led Health Cloud and Experience Cloud implementation activities as a Salesforce Senior Associate – Projects, with responsibility across technical design and delivery. Contributions included Identity and Consent Management architecture, secure integration design, access-control implementation, Experience Cloud performance optimization, architecture and code reviews, technical documentation, sprint planning, estimation and production root-cause analysis.
