## Site structure
- Home — professional introduction, featured implementation work and delivery outcomes
- Projects — seven anonymized implementation case studies and technical deep-dives
- Manufacturing Cloud Warranty Management — enterprise platform, architecture, integrations, security, scale and outcomes
- Sales Cloud — manufacturing sales process, opportunity management, automation, reporting and data migration
- Health & Experience Cloud — global patient-support program delivery, portal scale, identity and consent, secure integrations
- Integration Architecture — REST/SOAP, event-driven integration, Pub/Sub API, CDC, OAuth/SAML, resilience and security
- DevOps & Release Engineering — Salesforce DX, Git, Copado, environment governance and automated validation
- Performance Engineering — large data volumes, SOQL, Apex/LWC optimization and processing efficiency
- Service Cloud — confirmed Case Management, Omni-Channel Routing, Service Agent, Case Escalation, Auto-Response Rules and Email-to-Case; illustrative reference routing/SLA examples are labelled
- Services — technical capabilities and engagement models
- Architecture — original, anonymized reference diagrams for Manufacturing, Health/Experience, integrations, Service Cloud and CI/CD
- About — professional experience, certifications, awards, education and recommendation invitation
- Expertise — resume-backed technical capability map
- Hire Me — engagement areas
- Contact — professional contact details

## Deployment
GitHub Pages deploys through `.github/workflows/pages.yml` using GitHub Actions. The site is static HTML, CSS and SVG and requires no build step.

## Confidentiality and attribution
Case studies are anonymized. Client names, restricted production screenshots, proprietary data models, endpoints and confidential architecture are not published. Architecture diagrams are original portfolio-level reference diagrams. Service Cloud routing, Service Agent actions, SLA figures and operating targets marked illustrative are examples only, not verified historical project settings or achieved outcomes. Project-specific metrics are attributed to the respective engagement contexts.
